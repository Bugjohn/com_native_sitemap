# Native Sitemap

Native Sitemap is a lightweight Joomla 6 extension that automatically generates a clean XML sitemap using Joomla's native APIs.

The extension collects public articles, categories and menu items, removes duplicate URLs, generates a standards-compliant XML sitemap and ensures that your `robots.txt` file correctly references it.

## Features

- Native Joomla 6 extension
- Automatic XML sitemap generation
- Public articles, categories and menu items
- Duplicate URL removal
- `lastmod` support
- Standards-compliant XML output
- Automatic `robots.txt` synchronization
- Read-only `robots.txt` diagnostics
- XML preview before generation
- No external dependencies
- Clean and maintainable architecture

## Philosophy

Native Sitemap follows the same design principles as all ORKA CS projects.

- Business requirements come before code.
- Simplicity is a feature.
- Native Joomla APIs whenever possible.
- One class, one responsibility.
- No unnecessary dependencies.
- Built to remain maintainable for years.

## Requirements

- Joomla 6.x
- PHP 8.2+
